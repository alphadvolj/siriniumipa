# Sirinium

Sirinium — удобное приложение для просмотра расписания.  
<img src="/images/sirinium.png" alt="Логотип" width="200"/>

---

## Основные возможности:
 <img src="images/devices.png" alt="Светлая тема" width="400"/>

- Корректное отображение темы: светлая, тёмная и системная  
  <img src="images/white.jpg" alt="Светлая тема" width="300"/>  
  <img src="images/black.jpg" alt="Тёмная тема" width="300"/>

- Обзор расписания на несколько недель  
  <img src="images/weeks.jpg" alt="Расписание на несколько недель" width="200"/>

- Автоматическое переключение дня недели

- Показ следующей пары и аудитории  
  <img src="images/nextlesson.jpg" alt="Следующая пара" width="200"/>

- Интеграция с уведомлениями  
  <img src="images/noti.jpg" alt="Уведомление" width="200"/>

- Автообновление расписания
