# Sirinium

Sirinium — удобное приложение для просмотра расписания.  
![Логотип](/images/sirinium.png)
---

## Основные возможности:

- Корректное отображение темы: светлая, тёмная и системная  
  ![Светлая тема](images/white.jpg)  
  ![Тёмная тема](images/black.jpg)

- Обзор расписания на несколько недель  
  ![Расписание на несколько недель](images/weeks.jpg)

- Автоматическое переключение дня недели

- Показ следующей пары и аудитории  
  ![Следующая пара](images/nextlesson.jpg)

- Интеграция с уведомлениями  
  ![Уведомление](images/noti.jpg)

- Автообновление расписания
